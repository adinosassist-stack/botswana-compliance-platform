Security & control

Last updated: 13 October 2026. This page describes the security and governance principles visible in Thebe Desk today without making claims about controls that have not been independently certified.

Role-aware access

Thebe Desk is designed around authenticated access and role-based visibility so people can work with the business information appropriate to their responsibilities.

Human control for high-impact actions

AI can assist with analysis, preparation and guidance, while important business, legal, financial and regulatory decisions remain subject to human review and approval.

Workspace separation

The public marketing site is separated from authenticated workspace content. The public page is designed not to load private workspace data.

Evidence and review history

Thebe’s operating model connects evidence, responsibilities and actions so important work can be reviewed with context rather than relying only on unstructured messages.

Secure use is shared

Workspace owners should use strong credentials, restrict account access to authorised people, review user permissions when responsibilities change and avoid sharing sensitive information through unauthorised channels.

Reporting a security concern

If you believe you have found a security issue or suspect unauthorised access, contact Thebe Desk support through the support channel shown on the main website and provide enough detail for the issue to be investigated.

Security claims

Thebe Desk does not present this page as a certification, audit report or guarantee. Additional technical security documentation may be provided separately where appropriate.
