# V262 Property Operations

Property now has a compact post-acquisition Operations command centre inside the existing Thebe Property workspace.

## Scope

- Keeps `Today | Properties | Analyse | Operations` as the primary Property navigation.
- Replaces the Operations empty/valuation-only experience with an operating setup workspace.
- Uses current deal inputs only for monthly rent, annual rent, gross yield and setup-readiness calculations.
- Explicitly marks lease/tenant, rent collection, maintenance and expense records as `Connect data` until real operational sources exist.
- Adds Property AI draft actions for lease setup, rent collection and maintenance planning without auto-sending user messages.
- Keeps professional valuation as a separate existing panel within Operations.
- Adds dedicated responsive Operations styling and reduced-motion handling.

## Safety / truthfulness

The Operations UI does not synthesize live tenant, payment, arrears, maintenance or expense records. Missing sources remain visibly unconnected.
