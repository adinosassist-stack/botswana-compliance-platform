# V263 Property Optimise

Property gains a compact `Optimise` workspace for post-acquisition scenario planning.

## Scope

- Adds `Optimise` to the Property primary workspace navigation.
- Models a user-selected rent-change scenario from the current rent and purchase-price inputs.
- Shows baseline rent, scenario rent, annual rent change and scenario gross yield.
- Keeps refinance, capex and hold/sell incomplete until the required real debt, cost, valuation and sale inputs exist.
- Adds Property AI actions for stress testing, refinance input preparation, capex analysis and hold/sell input preparation.
- Does not auto-send AI prompts or represent scenario values as live market recommendations.
- Preserves the compact Property calculator, Operations workspace, grounded Property AI, mobile layout and DOM-safety constraints.
