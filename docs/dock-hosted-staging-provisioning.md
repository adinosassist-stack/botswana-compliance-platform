Do not expose credentials or seed the marker before actual database identity qualification. Node SQLite regression tests exercise the candidate lifecycle; a mocked D1 batch is not hosted evidence. Other workspace APIs and voice/history storage still require separate schema qualification within this batch. Rebinding the existing AI backend requires proving it will not disrupt any other staging acceptance path; otherwise use an independently reviewed isolated backend instance.
